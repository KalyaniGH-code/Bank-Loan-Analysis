# BANK LOAN ANALYSIS
## Summary
Bank loans serve as a vital financial instrument that empowers individuals and businesses to pursue their objectives and address various financial requirements. Nevertheless, it is imperative for borrowers to fully comprehend the associated terms, costs, and obligations to ensure sound and responsible financial decision-making.

## Data
Total Loan Applications: 38,600
Total Funded: $436 million
Total Amount Repaid: $473 million
Loan Quality: 86.2% were good loans, while 13.8% were bad loans
Average Interest Rate: 12.0%

## Toolkit
 1. MS SQL Server:
Learned how to create databases and tables, and use key functions such as SELECT, GROUP BY, ORDER BY, DATEPART, DATETRUNC,  CAST, MONTH, COUNT, DISTINCT, etc as well as advanced tools like CTEs and PARTITION for more complex queries.

 2. Power BI:
Gained experience in connecting to SQL Server, cleaning and shaping data, building data models, using Power Query and DAX, designing KPIs and visual dashboards (charts, cards), and enhancing reports with proper formatting and navigation.

# Key Insights :
1. High-Quality Lending: The majority of loans issued are classified as "good," suggesting strong portfolio performance and favorable returns for lenders.

2. Debt Consolidation Demand: The leading loan purpose is debt consolidation, reflecting an increasing need for financial restructuring among borrowers.

3. Growth in Digital Lending: A notable rise in online mortgage applications highlights a clear trend toward digital-first lending solutions.

4. Strategic Impact: These insights can help financial institutions enhance their loan approval frameworks, optimize risk management practices, and improve the overall customer experience.

# Technical Execution:
During the dashboard development, I applied DAX (Data Analysis Expressions) to construct dynamic, time-based performance metrics, including:
  1. MTD (Month-to-Date)
  2. YTD (Year-to-Date)
  3. PYTD (Previous Year-to-Date)
  4. MoM (Month-over-Month Growth)

These measures enabled real-time analysis of loan trends, empowering stakeholders with deeper insights into shifting borrowing patterns over time.
